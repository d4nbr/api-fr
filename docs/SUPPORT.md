# Suporte — Sala Livre

O **Sala Livre** é uma plataforma para gestão e utilização de espaços tecnológicos compartilhados, permitindo o acesso controlado a computadores, gerenciamento de salas e equipamentos e acompanhamento de sessões de uso.

Nesta página você encontra orientações para os problemas mais comuns.

## 1. Problemas para acessar um computador

### Os dados informados não conferem

Confira se os dados solicitados foram informados corretamente, como:

- CPF ou documento de identificação;
- data de nascimento, quando solicitada;
- número de registro profissional ou outro identificador, quando aplicável.

Os dados precisam corresponder às informações disponíveis nos sistemas integrados ao ambiente em que o Sala Livre está sendo utilizado.

Se os dados estiverem corretos e o problema continuar, procure o atendimento responsável pelo local ou utilize os canais de suporte do Sala Livre.

### Cadastro inativo ou acesso não autorizado

A situação cadastral identificada pelo sistema pode não permitir a liberação do computador naquele momento.

Procure a organização responsável pelo ambiente para verificar a situação do seu cadastro e as regras de utilização aplicáveis.

### Condição de acesso não atendida

Alguns ambientes podem possuir regras adicionais de utilização, definidas pela organização responsável e verificadas por meio de sistemas integrados.

Caso seja exibida uma mensagem indicando que alguma condição de acesso não foi atendida, procure a organização responsável para obter mais informações.

### Computador em manutenção

O equipamento está temporariamente indisponível para utilização.

Utilize outro computador disponível ou solicite auxílio ao responsável pelo local.

### Computador em uso

O equipamento já está sendo utilizado por outro usuário.

Escolha outro computador disponível ou aguarde a liberação.

### Já existe uma sessão ativa

O Sala Livre pode limitar o usuário a uma única sessão ativa por vez.

Caso você já esteja utilizando outro computador, encerre a sessão anterior antes de iniciar uma nova utilização.

Se você não estiver utilizando outro equipamento e a mensagem continuar aparecendo, procure o responsável pelo local ou entre em contato com o suporte.

### Limite de uso atingido

O tempo de utilização pode ser definido de acordo com as regras de cada sala ou ambiente.

Quando o limite disponível for totalmente consumido, uma nova sessão somente poderá ser iniciada quando houver nova disponibilidade de tempo, conforme as regras configuradas para o ambiente.

## 2. Problemas durante a utilização

### O computador foi bloqueado ou a sessão foi encerrada

A sessão poderá ser encerrada automaticamente quando:

- o tempo disponível for totalmente utilizado;
- a sessão for encerrada pelo próprio usuário;
- ocorrer alguma condição administrativa ou operacional que impeça a continuidade do uso.

Caso a sessão tenha sido encerrada indevidamente, procure o responsável pelo ambiente.

### O computador apresenta problema técnico

Se o equipamento apresentar travamentos, falhas de hardware, problemas de rede, periféricos defeituosos ou outra falha técnica, informe o responsável pelo local.

Não tente abrir o equipamento ou realizar alterações físicas sem autorização.

## 3. Impressão de documentos

Quando o recurso de impressão estiver disponível, o arquivo poderá ser enviado pelo computador utilizado e disponibilizado ao responsável pelo ambiente para realização da impressão.

Caso o arquivo não apareça para impressão:

- confirme se o envio foi concluído;
- procure o responsável pelo local;
- se necessário, realize novamente o envio.

Por segurança e privacidade, os arquivos enviados para impressão devem permanecer armazenados apenas pelo período necessário à execução do serviço, conforme as regras definidas para o ambiente.

## 4. Suporte para administradores e funcionários

Usuários autorizados podem solicitar suporte em casos relacionados a:

- acesso ao painel administrativo;
- recuperação ou alteração de senha;
- cadastro e gerenciamento de salas;
- cadastro e gerenciamento de computadores;
- equipamentos em manutenção;
- vínculo de usuários responsáveis às salas;
- acompanhamento de sessões;
- problemas de autenticação;
- problemas de impressão;
- dificuldades de acesso às funcionalidades da plataforma.

Sempre que possível, informe:

- seu nome;
- sala ou ambiente onde ocorreu o problema;
- identificação ou número do computador;
- data e horário aproximado;
- mensagem de erro exibida;
- descrição do que estava sendo feito no momento do erro.

Essas informações ajudam a equipe responsável a identificar o problema com mais rapidez.

## 5. Segurança

Nunca compartilhe sua senha ou credenciais de acesso.

Administradores, funcionários ou integrantes da equipe de suporte não devem solicitar a senha pessoal do usuário.

Em caso de suspeita de acesso indevido, informe imediatamente o responsável pelo ambiente ou o suporte do Sala Livre.
